# Phishing Email Detection Model - Mini Project Report

## Abstract
This project uses machine learning to classify email text as Phishing or Safe.

## Objective
To identify suspicious email messages using textual patterns and machine learning.

## Technologies
Python, Pandas, Scikit-learn, Matplotlib, Streamlit.

## Methodology
1. Load labeled email dataset.
2. Split data into training and testing sets.
3. Extract word and character TF-IDF features.
4. Train Logistic Regression.
5. Predict test emails.
6. Calculate accuracy.
7. Generate confusion matrix.
8. Test new email text.

## Expected Result
The system displays a Phishing/Safe prediction, accuracy, and confusion matrix.

## Limitation
The included dataset is small and educational. Real-world accuracy requires a much larger and diverse dataset.

## Conclusion
The project demonstrates how machine learning and text features can assist phishing-email detection.
