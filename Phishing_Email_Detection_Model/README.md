# Phishing Email Detection Model

## Features
- Phishing/Safe labeled dataset
- TF-IDF text feature extraction
- Logistic Regression
- Accuracy
- Confusion matrix
- Terminal prediction
- Streamlit web interface

## Install
```bash
python -m pip install -r requirements.txt
```

## Train
```bash
python train_model.py
```

## Predict
```bash
python predict.py
```

## Web App
```bash
python -m streamlit run app.py
```

Open the local URL shown in the terminal.

This is an educational project. Real-world deployment needs a larger, diverse dataset and further security validation.
